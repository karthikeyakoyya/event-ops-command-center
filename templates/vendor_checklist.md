# Vendor Coordination Checklist Template

Use this checklist per vendor when onboarding them into the Vendors table.

## Pre-Contract
- [ ] Vendor name, contact person, and email confirmed
- [ ] Scope of work / deliverable clearly defined in writing
- [ ] Quote received and within budget for this event
- [ ] Contract deadline set in Airtable (`Contract Deadline` field)

## Contract & Payment
- [ ] Contract sent for signature
- [ ] Contract signed by both parties → set `Contract Status` = "Signed"
- [ ] Deposit/payment terms confirmed
- [ ] Payment due date logged (`Payment Due Date` field)
- [ ] Payment sent → set `Payment Status` = "Paid"

## Pre-Event
- [ ] Final specs/measurements/requirements confirmed with vendor (e.g. booth dimensions, signage files, AV requirements)
- [ ] Delivery/setup timeline confirmed
- [ ] On-site point of contact exchanged both directions

## Day-Of
- [ ] Vendor delivery/setup confirmed on-site
- [ ] Any issues logged in Airtable notes field for post-event report

## Post-Event
- [ ] Final invoice reconciled against quote
- [ ] Vendor performance noted (would you use them again?) for future reference
